Privacy Notice

Last updated: 17 October 2026

This notice describes how the operator of this application handles information received through Login with Amazon.

This application uses Login with Amazon so you can sign in with your Amazon account and authorize an Amazon Ads API integration.

When you consent, Amazon may share your name, email address, and postal code with this application.

The operator of this application uses that information only to operate the Amazon Ads API integration: to identify the authorized account and to make the API calls you approved.

The operator of this application does not sell that information.

You can revoke this application's access at any time in your Amazon account, under Login with Amazon, by removing the application from the apps and services you have authorized.

Questions about this notice can be sent through the GitHub account that publishes this page: github.com/devrana13.
